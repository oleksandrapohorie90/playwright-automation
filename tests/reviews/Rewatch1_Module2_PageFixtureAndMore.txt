goto(url) - navigate to browser to specified URL; returns Promise need ot give await

title() - returns title of current page as str

url() - returns current url of current page as str; doesnt return promise - no need to give await

setViewSize({w,l}) - sets the size of the browser viewport to spefified width and height values

page.locator(selector) - crete a locator for given selector, 
which can be used to perform actions like click, type; locator object itself has lots of methods
**NOTE you can always give await but it will give a message that await word has no affect;
has auto waiting functionality;


for page.locator(selector) we can use:
        CSS selector: page.locator('button.primary')
        XPath selector: page.locator('//button[contains(text(),"Submit")]')
        Text content: page.locator('text=Submit')
        TestID: page.locator('data-testid=submit-button')

Once you located an element, you got locator object then you can use:
    Actions:
        click()
        fill() -> all chars at once
        type() -> chars one by one
        press() -> press Enter, CTRL any special keys; searchBox.press("Enter");
        check()
        uncheck()
        selectOPtion()
    Retrieval:
        textContent()
        innerText()
        inputValue()
        getAttribute()
    State:
        isVisible()
        isEnabled()
        isChecked()
        isDisabled()

Test Groups - to create we need to use test.describe(), which allows to organize related tests together; improves readability
and maintanability of out test suite; test groups can be nested for further organization
Test groups can have their own hooks that apply to all tests within the group; hooks can help to reduce duplication and provide 
teardown or setup

    -beforeEach() - runs bf each tc in the test group
    -afterEach() - runs after each ts in the test group
    -beforeAll() - runs once bf all tcs in test group
    -afterAll() - runs once after all tcs in test group

    test.beforeAll()
    for each test -> test.beforeEach() then test code and then test.afterEach()
    test.afterAll()
